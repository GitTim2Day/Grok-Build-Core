# MASK spec v2 (2026-10-10, supersedes v1 in lib/mask.py)

Author: Timothy Norman (sole author). Claude = tool/validator.

## Why
v1's only name rule was the surname of the kit's author, so it masked him and no one
else; any other real name passed through. Timothy (2026-10-10): his work may carry his
name, and masked text must still read naturally, so convincing reports and test forms
(CMS-1500) can be produced. Masking by "[NAME-MASKED]" tags made both impossible.

## Rules
- Contact data unchanged from v1: EMAIL, PHONE, HANDLE, ADDRESS, NUM -> [TAG-MASKED].
- Names: only KNOWN names are replaced (the list passed in, else lib/known_names.txt).
  No guessing at what looks like a name.
- One pass, longest name first, whole words, case-sensitive: a replacement is never
  masked again (no cascade).
- Placeholders by first appearance: John Q. Public, Jane Doe, Richard Roe, Mary Major,
  then Person 5, Person 6 ... The same real name keeps the same stand-in in one text.
- Placeholders are protected: they are never masked, even if a known name is part of one.
- The author's own name is not on the list by default.
- The same placeholder set is used for demos and test forms (Timothy, 2026-10-10), so a
  demo and a masked real record look alike and never show a real person.
- Residue audit flags any known name still present (placeholders excepted).

## Not here
Names inside structured forms (CMS-1500 patient and insured boxes) are masked by field
position in that form's extractor, not by text search.

## Honest limit
Free text is masked only for names the system has been told. A name nobody listed is
not caught; that is the price of not guessing.
