## Correction

Evidence accumulation is not probability assignment.
An added observation does not automatically strengthen a conclusion.
It may corroborate, contradict, or leave the conclusion unchanged.
That three-way result is the drift stop.

No invented confidence percentage.
No rounding away a discrepancy.
An inference is not an observation.
No drift means an assumption is never promoted into a fact.

## Rule

Acquire → Validate → Compare → Corroborate → Preserve provenance.

Acquire is not Compare. Validate rejects malformed input before Compare. Corroborate is the outcome of Compare, not a default upgrade.

## Comparison record

Each comparison is one of four states, stored with the measurements, the tolerance that came with those measurements, and the source record.

| State | Meaning |
| --- | --- |
| MATCH | Both sides observed. Difference is inside the stated tolerance. |
| MISMATCH | Both sides observed. Difference is outside the stated tolerance. Discrepancy kept. |
| INDETERMINATE | Both sides observed. Tolerance or overlap does not decide. |
| NOT OBSERVABLE | The structure is absent from that source. Absence is not a mismatch. |

Tolerance is not invented here. If the source has no tolerance, the comparison stays INDETERMINATE or NOT OBSERVABLE. It does not become MATCH.

## What each source may supply

Dental geometry: tooth position, shape, restoration, root configuration. Observation only if measured.
Skeletal geometry: dimensions and structural relations. Observation only if measured.
Facial geometry: landmarks and proportions. Observation only if measured. The Haar prototype is not this.
CT and other images: measurements that may confirm, refine, or contradict. PET remains tracer distribution, not equivalent anatomy.
