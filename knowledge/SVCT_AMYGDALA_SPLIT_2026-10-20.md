# Amygdala split and two intakes

When: the sides mix channels, or a sensor arrives by USB or by a GPIO attachment.

## His sentence
If we see sides mixing channels, then we break it into two separate amygdalas, and they both are one way in opposite directions.
Those nodes process all the data the same way per node or sensor.
If the data comes in through a USB plug-in, it has access to our code or to the plug-and-play code.
If it is built inside and attached as if it were a GPIO to a device, it takes the data in from that version.
Process it the same way.
Once it is converted to text, it all pans out.

## What changed
The 19:31 rule said: if a side mixes channels, stop.
This sitting replaces that consequence. Seeing the mix does not blend the sides. It splits the parser.

One amygdala, one direction.
The other amygdala, one direction, the opposite way.
They stay separate.

Until a mix is seen, the 19:31 placement stands: one amygdala, both ways, no blend.

## Same process, two intakes
The process per node is the same. The intake is not.

USB plug-in. Access to our code, or to the plug-and-play code. The named USB sensor on the shelf is the eMeet at /dev/video0. Which of the two codes it uses was not said. Not invented.

Built in, attached as a GPIO. Take the data from that version. The 12 Sep note still stands beside this: Pi 5 GPIO is RP1, pigpio does not run there, precision GPIO is the Pico 2. "Attached as a GPIO" is the class. It does not make the Pi 5 the clock.

After intake, one process.
After the bytes are text, one path. That is the pan-out. It matches CSVSON: the filter first, then text, then the join. A plate is still a filter, not the parser.

## Rule
IF the sides mix channels THEN split into two amygdalas.
Each is one way.
The directions are opposite.
IF they are joined back into one blend THEN stop.

IF the intake is a USB plug-in THEN our code OR the plug-and-play code may read it.
IF the intake is built in and attached as a GPIO THEN that version reads it.
THEN the process is the same.
IF the data is text THEN the paths are one path.
