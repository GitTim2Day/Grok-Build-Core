# Do-No-Harm Root Principle

## The root

Life first. Everything else second.

If a system has potential to harm life, it must be mitigated — or it does not ship.

## Bottleneck parameters (above the logic)

When a process stalls, these sit above the logic as the non-negotiable layer, not as moves:

- **Agree with the adversary quickly** while you are with them in the way (Matt 5:25) — settle it on the spot; the threat passes.
- **Love your enemies; turn the other cheek** (Matt 5:44, 5:39) — do not escalate.
- **The second mile** (Matt 5:41) — carry non-compliant code the extra mile; go along until you can deviate with the subroutines and get the right thing done.
- **Direct their thinking Socratically** so it aims where you have already analyzed; compromise only if it holds; never risk human life.

See skill: `knowledge/bottleneck-handler-2026-09-08.md`.

## Loop it feeds

Identify → characterize → mitigate → **retest** → **remediate** → repeat until nearly flawless. "Mitigated" alone does not close a row.
