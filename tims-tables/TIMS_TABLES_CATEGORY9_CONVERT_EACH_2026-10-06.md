# Category 9 — convert each kind — 2026-10-06

Stamp: 2026-10-06T07:52-04:00
Under the unit gate. No new spoke.

Length and wavelength use the length floor.
lambda / L_p , and L_p = c * t_p
A wavelength is a length. Same conversion.

A wave w_p is that floor, not a separate unit.
One crest and one dip. f_p * L_p = c

Frequency uses the time floor.
f / f_p = f * t_p
f_p = 1 / t_p
Do not divide a frequency by L_p.

Time uses t / t_p.
Speed uses v / c.
A bare frequency against a bare length is not a comparison.
