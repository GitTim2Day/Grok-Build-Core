## Special relativity

Let S = √(C² − V²). S > 0, so V < C.
γ = C / S.

| ID | Formula |

| E | E(M) = M C³ / S |
| PR | PR(M) = M V C / S |
| KX | K(M) = E(M) − E0(M) = M C² (C − S) / S = M V² C² / (S (C + S)) |
| INV | E² − (PR C)² = (M C²)² |
